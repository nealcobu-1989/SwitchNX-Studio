# SwitchNX Studio 1.0.1

Changes since 1.0. / Cambios desde la 1.0.

## English

Doctor
- **Mod files open from the SD** now counts **mod plugins**, which is what decides the limit. Tests on
  a real pack (Nov 2026): with 84 mod plugins the game lost message boxes and dialogue options often,
  with 83 it still lost one (a standing stone's), with 76 to 82 everything showed. The number of BSAs
  made no difference: joining BSAs didn't help, merging plugins did. Warning from 80, serious from 83.
  ESL plugins count; Creation Club and the game's own files don't.

Guide and manual
- The **Limits** table has a row for mod plugins.
- The guide's troubleshooting table no longer blames the CPU overclock or script load for empty message
  boxes; it points to the plugin count. The overclock and the Papyrus budgets in Skyrim.ini stay as
  general performance help.
- New tip: if something odd shows after loading several saves in one session (a modded NPC with no
  dialogue, a loading screen that stays on), close the game completely and start it again before
  loading.

Leftover BSAs
- Old BSAs left in a pack after joining files by hand came from edits made outside the app. When the
  join is done in the app, it rebuilds the pack from its own copy and removes the files that are no
  longer part of it (or moves them to the trash), so nothing changed there.

## Español

Doctor
- **Archivos de mods abiertos desde la SD** ahora cuenta **plugins de mods**, que es lo que decide el
  límite. Pruebas en un pack real (nov. 2026): con 84 plugins de mods el juego perdía letreros y
  opciones de diálogo seguido, con 83 todavía perdió uno (el de una piedra guardiana), con 76 a 82 todo
  salió. La cantidad de BSA no cambió nada: juntar BSA no ayudó, fusionar plugins sí. Aviso desde 80,
  grave desde 83. Los plugins ESL cuentan; los de Creation Club y los del juego no.

Guía y manual
- La tabla de **Límites** tiene una fila para plugins de mods.
- La tabla de problemas de la guía ya no culpa al overclock ni a la carga de scripts por los letreros
  vacíos; apunta a la cantidad de plugins. El overclock y los presupuestos de Papyrus en Skyrim.ini
  quedan como ayuda general de rendimiento.
- Consejo nuevo: si algo raro aparece después de cargar varias partidas en la misma sesión (un NPC de
  un mod que no habla, una pantalla de carga que se queda), cierra el juego del todo y ábrelo otra vez
  antes de cargar.

BSA sobrantes
- Los BSA viejos que quedaron en un pack después de juntar archivos a mano venían de cambios hechos
  por fuera de la app. Cuando se juntan desde la app, esta rearma el pack desde su propia copia y quita
  los archivos que ya no son parte de él (o los manda a la papelera), así que ahí no hubo cambios.
